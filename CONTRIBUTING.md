
# Contributing to Decentralized Mesh Protocol 🚀

Welcome to the **Decentralized Mesh Protocol** Hackathon! We are excited to have you contribute to our open-source project. Please follow these guidelines to make the contribution process smooth and effective for everyone.

---

## 📜 Code of Conduct & Rules

1. **No Direct Pushes:** All contributions must be submitted via **Pull Request (PR)** targeting the `main` branch. Direct pushes are blocked.
2. **Issue First:** Before creating a PR, make sure an issue is assigned to you. If no issue exists, open a new issue and wait for maintainers to assign it to you.
3. **No Spam PRs:** Unnecessary formatting changes, fixing tiny typos in comments, or spam PRs will be closed immediately without points.

---

## 🛠️ How to Contribute

### Step 1: Fork and Clone:

1. Fork this repository to your GitHub account.
2. Clone your forked repo:
   ```bash
   git clone [https://github.com/YOUR_USERNAME/Decentralized-Mesh-Protocol.git](https://github.com/YOUR_USERNAME/Decentralized-Mesh-Protocol.git)
   cd Decentralized-Mesh-Protocol

Step 2: Create a Feature Branch:

Always create a new branch for your work:
git checkout -b feature/your-feature-name

Step 3: Commit and Push:

Keep your commit messages clear and concise:
git add .
git commit -m "feat: added ESP32 node routing logic"
git push origin feature/your-feature-name

Step 4: Submit a Pull Request (PR)
 * Go to the original repository on GitHub.
 * Click New Pull Request.
 * Link the assigned issue in your PR description (e.g., Fixes #12).
 * Wait for the maintainers to review your code.
🎯 Evaluation & Rewards
 * Maintainers will review every PR for code quality, documentation, and logic.
 * Merged PRs will earn points based on issue difficulty.
 * Top 30 Contributors will receive cash prizes!
 * All valid contributors will receive participation certificates.
